PyDuino Image Understand is a fast, local-first desktop app that generates **captions, OCR text, and embeddings** with full GUI + CLI control. Download once, run offline, and keep your data on-device.

Built for builders and teams who live in screenshots: extract UI text, summarize diagrams, label datasets, and generate clean descriptions you can paste directly into docs or tickets. Everything runs locally, so sensitive images never leave your machine.

Choose your model, control prompt length, and decide exactly where outputs are saved. The GUI keeps things friendly while the CLI keeps workflows fast and scriptable.
